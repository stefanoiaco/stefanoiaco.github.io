# Stefano Iacovino — Portfolio

Personal portfolio website for GitHub Pages.

## Publish

1. Open the repository `stefanoiaco/stefanoiaco.github.io`.
2. Upload `index.html` to the root of the repository.
3. Commit the change to the `main` branch.
4. If needed, open **Settings → Pages** and select **Deploy from a branch**, then choose `main` and `/ (root)`.
5. Your site will be available at `https://stefanoiaco.github.io`.

All content and styling are contained in `index.html`.
